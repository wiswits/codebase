# 03 · Parents and Linking

**Domain:** People
**Status:** LIVE (link surface partially wired)

**What it is:** Connects guardians to students so fees, attendance, report cards and events reach home.

## Features
- Parent accounts + child linking by invite code
- My Children view
- Parent portal access to fees/attendance/reports
