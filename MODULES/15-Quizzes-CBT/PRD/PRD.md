# PRD — Quizzes CBT

**Purpose.** Computer-based testing. Coaching & Test Series intern build = future feature mine (batches, OMR, doubts, error-book) — additions here, not a new module.

**Primary roles.** teacher, student, parent (view)

**Core workflow.** Teacher builds quiz from bank → students attempt → analytics per question/student.

## Scope (current edition)
- Quiz create/attempt/analytics
- Parent view
- Separate quiz-portal app for standalone use
