# 🚀 EduSuite Recruitment Management Assembly

Final integrated Recruitment Management module for the EduSuite ERP platform.

---

# 📖 Overview

This module manages the complete recruitment lifecycle from vacancy creation to hiring.

It integrates frontend, backend and database into a single deployable module.

---

# ✨ Features

- Recruitment Dashboard
- Vacancy Management
- Applicant Management
- Resume Upload
- Recruitment Pipeline
- Interview Scheduling
- Offer Management
- Dashboard Analytics
- Search & Filters
- API Integration
- Database Integration
