**Primary roles.** admin, principal, class teacher

**Core workflow.** Pick template → bind assessment data → preview → publish → parent/student access.

## Scope (current edition)
- Designer with full-width layout
- ONE renderer for screen + PDF
- Publish workflow

  states, SimLab design, simple-English copy).

  ERP/LMS jargon · beautiful by default.
