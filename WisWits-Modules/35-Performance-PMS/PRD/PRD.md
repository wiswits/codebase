# PRD — Performance PMS

**Purpose.** Appraisal-season workflows for schools — goal setting and review cycles — WITHOUT becoming corporate HR software (§16 risk flagged).

**Primary roles.** principal, hr_manager; staff self

**Core workflow.** Set goals per term → self-review → principal review → outcome recorded.
