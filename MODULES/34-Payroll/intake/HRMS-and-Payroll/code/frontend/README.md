A complete Human Resource Management System with Payroll, Leave Management, CPD Tracker, Appraisal, Exit & F&F Settlement.

## 📋 Features

### ✅ Employee Management
- Add/View/Update/Delete Employees
- Employee Documents Upload
- Qualifications Tracking

### ✅ Leave Management
- Multiple Leave Types (CL, EL, SL, ML, Comp-Off)
- Apply Leave
- Approve/Reject Leave

### ✅ CPD Tracker (NEP 50 hrs/year)
- Log CPD Activities
- Verify/Reject CPD
- Progress Dashboard

### ✅ Appraisal System
- Create Appraisal Cycles
- Add KRAs
- Employee Appraisals

### ✅ Exit & F&F Settlement
- Initiate Exit
- Full & Final Settlement Calculation

### ✅ Payroll
- Salary Components
- Salary Structure Assignment
- Payroll Runs (Draft → Lock → Approve)

### ✅ Reports
- Employee Master Report
- Leave Ledger Report
- CPD Compliance Report
- Appraisal Report
- Exit Report
- CSV Download

### ✅ Profile
- View Profile
- Edit Profile

### ✅ Dark Mode
- Toggle Light/Dark Theme
