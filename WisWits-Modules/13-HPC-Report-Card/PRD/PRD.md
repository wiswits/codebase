# PRD — HPC Report Card

**Purpose.** NEP-mandated holistic progress format. Ports as a template/extension of Report-Cards (#12), keeping one report-card system.

**Primary roles.** principal, class teacher

**Core workflow.** Define competencies per cycle → teacher observations → holistic card generated per student.

## Scope (current edition)
- NEP Holistic Progress Card
- Competency workspace by cycle
- Card preview + summary

## Requirements (inherited, non-negotiable)
- Module anatomy per `PRODUCT_PRD.md` §2 (org_id scoping, permissions, audit, six loading
  states, SimLab design, simple-English copy).
- §1 Product Principles: reduces teacher workload · ≤3 clicks · mobile-first · no
  ERP/LMS jargon · beautiful by default.
- Definition of Done: `CLAUDE.md` §20, all eleven points.
