# PRD — Curriculum CIE

**Purpose.** The Curriculum Intelligence Engine — grade-agnostic concept graph mapped across boards. Phase 1 live in code; changes nothing for a school until revealed.

**Primary roles.** admin/principal (setup); all school roles (view)

**Core workflow.** School picks board → curriculum mapped → teaching surfaces bind to concept nodes.

## Scope (current edition)
- Concept nodes + board mapping (Atlas)
- School curriculum setup (board choice)
- My Curriculum / Learn / Assignments surfaces

- Module anatomy per `PRODUCT_PRD.md` §2 (org_id scoping, permissions, audit, six loading
  states, SimLab design, simple-English copy).
- §1 Product Principles: reduces teacher workload · ≤3 clicks · mobile-first · no
  ERP/LMS jargon · beautiful by default.
