# Employee Management & Productivity System (EMPS) - Frontend

## Overview
The frontend application for the Employee Management & Productivity System built with React.js, Tailwind CSS, and Redux Toolkit.

## Features
- Role-based authentication (Admin, HR, Manager, Employee)
- Real-time chat with Socket.io
- Interactive dashboards with charts
- Attendance tracking with location
- Task management with progress tracking
- Leave management with approval workflow
- Meeting scheduling with calendar
- Document management with upload
- Announcements and notifications
- Responsive design with dark mode support

## Technology Stack
- React.js 18
- Redux Toolkit
- Tailwind CSS
- Socket.io Client
- Recharts
- React Router v6
- React Hook Form
- Framer Motion
