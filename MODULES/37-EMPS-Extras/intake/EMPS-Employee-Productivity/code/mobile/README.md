# EMPS Mobile App

## Overview
Mobile application for the Employee Management & Productivity System built with React Native.

## Features
- Employee authentication
- Dashboard with statistics
- Attendance tracking
- Task management
- Leave management
- Real-time chat
- Profile management
- Push notifications

## Technology Stack
- React Native 0.72
- React Navigation 6
- Axios for API calls
- AsyncStorage for local storage
- React Native Vector Icons

## Installation

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn
- Android Studio / Xcode
- iOS Simulator / Android Emulator
