# PRD — SQAAF

**Purpose.** School Quality Assurance and Assessment Framework: the self-assessment and
quality-audit cycle a school runs against itself — domains, indicators, evidence, score,
improvement plan.

**There is no native spec yet, and that is the honest state.** This slot exists because
SQAAF is the one intern module with **no counterpart anywhere in the 60** — it is not a
duplicate of anything we run, so it could not be folded into another module's `intake/`.

**The spec that does exist** is the intern team's written contract:
`../intake/SQAAF/PRD/`. Zero code was ever written for it, here or upstream. Anyone
picking this up builds from that contract and writes the real PRD here first.

**Before building, it must clear §1 Product Principles and §16** — a quality-audit
workbench is close to the "generic ERP" line, so scope it school-sized and teacher-light,
or it fails the filter.

Current status: **GAP — contract only** — see `../STATUS.md`.
